# 形式変換

動画・音声・画像・PDF の形式変換、結合、切り出しをまとめて行う macOS 用のローカルWebアプリです。
ファイルは Mac の外に送信されません（`127.0.0.1` のみで待ち受け）。

## 主な機能
- 動画 / 音声 / 画像の形式変換、動画から音声の抽出
- 動画・音声の結合、画像 → 1つのPDF、PDF → 画像、動画 → 静止画
- 開始/終了位置の切り出し、再生速度、音量そろえ、無音カット、目標サイズ指定の圧縮
- 字幕(.srt)の埋め込み/焼き込み、音声のタグ・カバー画像、画像のリサイズ・EXIF削除
- フォルダ一括変換、プリセット保存、プレビュー、変換履歴

## 必要なもの
- macOS、Python 3（標準の `/usr/bin/python3` で可）
- `ffmpeg`（`brew install ffmpeg`）
- `pip3 install pillow pymupdf`

## 起動
```bash
python3 server.py
```
または `形式変換.app` / `起動.command` をダブルクリック（このフォルダ内に置いたまま使用）。
ブラウザで http://127.0.0.1:8765/ が開きます。変換結果は `変換済み/` に保存されます。
